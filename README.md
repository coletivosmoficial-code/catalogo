# Catálogo Coletivo do Smart

Site público do catálogo, com pedido pelo WhatsApp. Publicado pelo GitHub Pages.

- `index.html`: a página (carrinho e envio do pedido pelo WhatsApp)
- `dados.json`: produtos e preços de venda, gerados todo dia a partir do catálogo interno
- `fotos/`: miniaturas dos produtos

Este repositório não contém custos, margens nem fornecedores. Os arquivos `dados.json` e `fotos/` são regenerados automaticamente; não edite à mão.
